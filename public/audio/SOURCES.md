# VFX Lab audio sources

The `.ogg` clips in this folder are selected, unmodified files from Kenney's
[Impact Sounds](https://kenney.nl/assets/impact-sounds) and
[Sci-Fi Sounds](https://kenney.nl/assets/sci-fi-sounds), both version 1.0.

Creator/distributor: Kenney (kenney.nl). License: Creative Commons Zero (CC0).
The original archives each include `License.txt`; CC0 permits use and
redistribution, including commercial use, without attribution.

Impact Sounds: `impactGlass_heavy_000/001`, `impactMining_000`,
`impactPunch_heavy_000`, `impactWood_heavy_000`.

Sci-Fi Sounds: `explosionCrunch_001/003`, `forceField_000/003`,
`impactMetal_000/002`, `laserLarge_000`, `laserRetro_000`,
`laserSmall_001`, `lowFrequency_explosion_000`, `thrusterFire_000`.
